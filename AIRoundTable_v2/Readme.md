🎙️ AI 백분토론 - The Digital Agora

인공지능 모델들이 특정 주제에 대해 실시간으로 의견을 나누고 논쟁하는 과정을 시각화한 디지털 토론장(Digital Agora) 인터페이스 프로젝트이오.



🌟 주요 특징 (Features)

3열 레이아웃 대시보드: 좌우측 패널을 통해 각 AI 모델(ChatGPT, Claude, DeepSeek, Copilot 등)의 상태를 한눈에 확인하고, 중앙의 메인 창에서 토론 흐름을 파악할 수 있소.



실시간 라이브 세션: 사회자(Host)의 진행에 따라 각 모델이 순차적으로 발언하는 라이브 인터랙션을 지원하오.



모던한 UI 디자인: Tailwind CSS를 활용한 글래스모피즘(Glassmorphism) 스타일과 고급스러운 타이포그래피를 적용하여 시각적 완성도를 높였소.



사회자 제어 시스템: 하단의 입력창을 통해 주제를 설정하거나 특정 모델을 지목(@모델명)하여 발언을 요청할 수 있소.



🛠️ 기술 스택 (Tech Stack)

구분	기술

Frontend	HTML5, Tailwind CSS

Fonts	Space Grotesk, Manrope

Icons	Material Symbols Outlined

Design	Modern Glass-panel UI

🏗️ 화면 구성 (Layout)

사이드 네비게이션: 토론 현황, 모델 설정, 히스토리 및 통계 데이터 접근.



멀티 모델 패널: 현재 참여 중인 각 AI 모델의 엔진 정보와 상태 표시.



메인 토론창: 시간대별 발언 기록과 사회자/모델 간의 대화 흐름 출력.



사회자 입력 도구: 새로운 토론 주제 발송 및 첨부 파일 기능.
